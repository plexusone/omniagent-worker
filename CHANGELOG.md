## [v0.1.0] - 2026-07-11 ([`d2b2891`](https://github.com/plexusone/omniagent-worker/commit/d2b2891))

### Highlights

- Initial release of omniagent-worker, a Go-first multi-agent worker framework
- Minimal Worker interface for building task-oriented agents
- Coordinator for managing worker teams with workflow support
- Pool for in-process worker management (embedded use)

### Added

- Core `Worker` interface with ID, Type, Version, Init, Shutdown, Health, Execute methods ([`6266d8a`](https://github.com/plexusone/omniagent-worker/commit/6266d8a))
- `WorkflowExecutor` interface for workflow step execution ([`6266d8a`](https://github.com/plexusone/omniagent-worker/commit/6266d8a))
- `BaseWorker` implementation with configurable ID, Type, Version, and lifecycle management ([`a20d795`](https://github.com/plexusone/omniagent-worker/commit/a20d795))
- `WorkerConfig` struct for worker configuration ([`a20d795`](https://github.com/plexusone/omniagent-worker/commit/a20d795))
- `Pool` for in-process worker management with Register, Unregister, Dispatch, and Health operations ([`44a9ea2`](https://github.com/plexusone/omniagent-worker/commit/44a9ea2))
- `Coordinator` for workflow orchestration with Pool integration ([`bd166fe`](https://github.com/plexusone/omniagent-worker/commit/bd166fe))
- `CoordinatorConfig` and `CoordinatorRequest`/`CoordinatorResponse` types ([`bd166fe`](https://github.com/plexusone/omniagent-worker/commit/bd166fe))
- `WorkerClient` for HTTP-based remote worker communication ([`14028a3`](https://github.com/plexusone/omniagent-worker/commit/14028a3))
- HTTP `server` package with RESTful API, health endpoints, and graceful shutdown ([`82085c4`](https://github.com/plexusone/omniagent-worker/commit/82085c4))
