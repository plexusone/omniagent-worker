# Release v0.1.0

**Release Date:** 2026-07-11

## Highlights

- Initial release of omniagent-worker, a Go-first multi-agent worker framework
- Minimal Worker interface for building task-oriented agents
- Coordinator for managing worker teams with workflow support
- Pool for in-process worker management (embedded use)
- HTTP server for standalone worker deployment
- Full observability support via OpenTelemetry-compatible tracing

## Features

### Core Worker Interface

The `Worker` interface provides a minimal contract for task-oriented agents:

- `ID()` - Unique worker identifier
- `Type()` - Worker type classification
- `Version()` - Semantic version
- `Init(ctx)` - Initialize resources
- `Shutdown(ctx)` - Cleanup resources
- `Health(ctx)` - Health check with status and details
- `Execute(ctx, req)` - Process requests and return responses

### BaseWorker Implementation

`BaseWorker` provides a ready-to-use implementation with:

- Configurable ID, Type, and Version
- Lifecycle management (Init/Shutdown)
- Health reporting with status and details
- Request/Response handling with metadata support

### Pool for In-Process Workers

The `Pool` manages workers within a single process:

- Register and unregister workers dynamically
- Dispatch requests to workers by ID
- Health checks across all registered workers
- Thread-safe worker management

### Coordinator for Workflows

The `Coordinator` orchestrates multi-worker workflows:

- Workflow execution with step-based processing
- Support for sequential and parallel execution patterns
- Integration with Pool for in-process workers
- Integration with WorkerClient for remote workers

### WorkerClient for Remote Communication

`WorkerClient` enables communication with remote workers:

- HTTP-based request/response protocol
- Health check endpoints
- Configurable timeouts and retry policies

### HTTP Server

The `server` package provides production-ready HTTP serving:

- RESTful API for worker operations
- Health check endpoints
- Graceful shutdown support
- Middleware for logging and metrics

## Installation

```bash
go get github.com/plexusone/omniagent-worker
```

## Quick Start

### In-Process Workers

```go
coord := worker.NewCoordinator(worker.CoordinatorConfig{
    ID: "my-coordinator",
})
coord.Pool().Register(NewMyWorker())
resp, err := coord.Execute(ctx, &worker.CoordinatorRequest{
    Input: map[string]any{"topic": "example"},
})
```

### Standalone HTTP Server

```go
myWorker := NewMyWorker(worker.WorkerConfig{
    ID:   "my-worker",
    Type: "processor",
})
server.Run(ctx, myWorker, server.Config{Port: 8080})
```
